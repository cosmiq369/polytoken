The query, through Zetaris

sql/token_ratio_by_part.sql
SELECT i.company, n.tokenizer_spec, i.part,
       COUNT(*)      AS paired_items,
       SUM(n.tokens) AS native_tokens,
       SUM(e.tokens) AS english_tokens,
       CAST(SUM(n.tokens) AS DOUBLE) / SUM(e.tokens) AS native_to_english_ratio
FROM inputs i
JOIN company_systems.measurements__latest_token_counts n ON ...
JOIN company_systems.measurements__latest_token_counts e ON ... AND e.lang_variant = 'en'
GROUP BY i.company, n.tokenizer_spec, i.part

One query joins the company's chats, the token measurements and the reference corpus. The checker then recomputes every group from the raw rows and refuses the report if any count differs.
