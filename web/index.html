    Where things run

    Candidate tokenizers · this machine

    Standard model-fit investigations do not call Llama, Gemma or the other ranked candidates. Cached tokenizers count the supplied text locally; verified, dated price quotes come through Zetaris SQL.

    Nemotron · hosted NVIDIA API

    Live planning sends workload summaries to NVIDIA. One injected generator handles planning and judging. An explicitly requested quality experiment also sends conversation context for judging.

    Zetaris · your installation

    Local Docker by default. Company data and measurements live in the configured PostgreSQL. Sourced observations also persist in World Model SQLite and JSONL logs. Remote installations receive the data they query.

    Meterless · in this Python process

    In-repo Python implementations against a pinned reference specification: World Model evidence, H-MEM company memory and Markovian carryover. No Meterless package installation is required.

    Quality · verify on your sample

    The recorded controlled experiment used hosted openai/gpt-oss-20b as a stand-in after the other tested models failed serving probes. Its results do not establish candidate quality or voice latency.

    Demo and Ask · checked saved evidence

    Demo replays synthetic-company runs without external network calls; the browser only contacts this local app. Ask the evidence reads checked saved claims without a model call. Uploads need live mode.
